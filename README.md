# Driver State Intelligence

AI-assisted race engineering dashboard for analyzing driver radio communication, driver state, race performance, and telemetry signals.

## Overview

The system combines:

- Driver radio communication analysis
- Driver state and stress monitoring
- Lap and sector performance
- Telemetry analysis
- Driver state vs performance correlation
- Engineer-focused insights
- Session history

## Frontend

The frontend is built with:

- React
- TypeScript
- Vite
- Tailwind CSS
- Recharts
- Lucide React
- Motion

## Current Development Phase

The current frontend prototype uses mock data and React local state.

No backend or API integration is currently required.
